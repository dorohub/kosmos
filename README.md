# KOSMOS · Universal-Navigator

Fliege nahtlos von der Erdoberfläche bis an den Rand des beobachtbaren Universums – durch die Milchstraße, zu Sternen und ihren Planeten, durch Galaxienhaufen und das kosmische Netz.

**Live:** https://dorohub.github.io/kosmos/

## Lokal starten

```bash
npm install
npm run dev
```

Oder auf dem Mac per Doppelklick auf `KOSMOS starten.command` (inkl. Zugriff vom Handy im selben WLAN).

## Steuerung

Ziehen = drehen · Mausrad = zoomen · Rechtsklick = schwenken · WASD = fliegen · `H` = alle Tastenkürzel
